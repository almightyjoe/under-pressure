# under-pressure

JJ's Pressure Test Analyzer. Enter 1-minute pressure readings, see the loss trend, and get a PASS / FAIL against the pressure-test criteria (minimum test pressure with a maximum, loss rate over the last 5 minutes, total loss, loss trend). It finds the best N-minute stretch that meets the criteria.

## Phone version (GitHub Pages)
`index.html` at the top level is the phone version (MOBILE REV 1.1). Open it on an iPhone or Android and use "Add to Home Screen". It works offline after the first visit.

## Desktop version
`desktop/JJs-Pressure-Test-Analyzer-REV1.7.html` is a single file. Download it and open it in any browser; no install needed. It adds loading a test log (CSV), a chart with hover and drag-to-select, and unlimited readings. REV 1.6 is kept as the fallback.

See `CHANGELOG.md` for the revision history.

This is a calculation aid. Confirm results against your official test criteria.
